# 🌾 Crop Yield Prediction & Farm Insights App

This project is a Machine Learning-powered web application that predicts crop yield based on environmental and farm management factors. It also provides fertilizer recommendations, Ghana-focused agricultural insights, and downloadable farm reports.

The application is built using Python, Scikit-learn, and Streamlit, and demonstrates an end-to-end data science workflow from model training to deployment.

---

## 🚀 Features

✅ Crop yield prediction using Random Forest  
✅ Feature importance visualization  
✅ Yield comparison across multiple crops  
✅ Optimal fertilizer recommendation calculator  
✅ Ghana-specific farming insights  
✅ Live weather data integration (API-based)  
✅ Downloadable PDF farm report  
✅ Interactive Streamlit user interface  

---

## 🧠 Machine Learning Model

The model uses:

- Random Forest Regressor
- One-hot encoding for categorical variables
- Train-test split validation
- Performance metrics:
  - Mean Absolute Error (MAE)
  - R² Score

Input features include:

- Rainfall (mm)
- Temperature (°C)
- Fertilizer (kg/ha)
- Farm area (hectares)
- Soil type
- Crop type

## 📊 Use Case

This system can help:

- Farmers optimize fertilizer usage
- Agricultural advisors support decision-making
- Researchers analyze crop performance trends
- Policymakers understand productivity factors

It is especially relevant for smallholder farming systems in Ghana and similar regions.

## 🌍 Ghana-Focused Insights

The app provides contextual recommendations based on:

- Rainfall patterns similar to Northern and Southern Ghana
- Temperature stress conditions affecting crop yield
- Practical fertilizer usage guidance

## 📄 Farm Report

- Fertilizer usage
- Weather conditions
- Farm parameters
